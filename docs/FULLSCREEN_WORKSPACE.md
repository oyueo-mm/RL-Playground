# 전체 화면 GridWorld 및 플로팅 툴바

`feat/home-redesign`, 기준 `e02fa11`에서 이어서 구현했다. 이 문서는 이전
`LAB_LAYOUT_UPDATE.md`의 세로 캔버스·하단 분석 패널 설계를 대체한다.

## 화면과 상태

- 학습·편집 화면은 브라우저 높이에 고정된 애플리케이션이다. 사이드바 외의 영역을
  맵에 할당하고 경로, 큰 제목, 설명, 브랜드 장식을 시각적으로 제거했다. 숨김 제목과
  ARIA 레이블은 유지한다. 홈 소개와 알고리즘 가이드는 보존했다.
- `GridViewport`는 `ResizeObserver`로 실제 남은 가로·세로 공간을 측정한다.
  `min((가로-여백)/열, (세로-여백)/행)`을 사용해 정사각형 셀과 맵 비율을 유지한다.
  창 크기, 사이드바, 분석·속성 패널 변경과 비활성 화면 복귀를 반영한다.
- `FloatingToolbar`도 높이를 실측한다. 버튼이 줄바꿈되면 격자가 툴바 아래에서 맞춰진다.
  상단에 거대한 고정 여백을 예약하지 않는다.
- 기본은 전체 맞춤이다. 100–300% 확대와 전체 맞춤 복귀를 제공하고, 확대 시 스크롤·터치
  패닝은 격자 뷰포트 안에서만 발생한다. 브라우저 페이지는 스크롤하지 않는다.
- 분석은 데스크톱 우측의 독립 스크롤 패널이다. 모바일은 맵을 가리지 않는 하단 분할
  패널을 사용한다. 설정은 툴바 팝오버다. 결과 메뉴는 분석만 보여주는 독립 화면이다.
- `scrollIntoView()`로 메뉴를 연결하지 않는다. 단일 Simulator·SimulationEngine과 편집기를
  계속 마운트하고 화면 visibility만 바꾼다. 실험·Q-table·셀·에피소드·학습 상태가 유지된다.
  수정 전 초안은 새 실험 맵을 따라가고, 수정한 초안은 다른 맵·화면으로 이동해도 유지한다.

## 학습 컨트롤과 시각화

- 속도 슬라이더, 학습, 일시정지/재개, 학습 중단, 학습 결과 실행, 시각화, 설정, 맵, 분석.
- Step·초기화 버튼은 기본 화면에서 제거했다. 엔진 `step()`·`reset()` API는 유지한다.
- ‘학습 중단’은 기존 `restartEpisode()`의 안전한 중단 경로다. 스케줄러를 취소하고 현재
  미완료 에피소드만 버린 뒤 시작점으로 돌아온다. Q-table과 완료된 학습 이력은 유지한다.
  취소한 에피소드를 완료 기록에 넣지 않는다. 맵 적용과 알고리즘 변경은 명시적인 초기화 경계다.
- 정책·가치는 기본 활성화다. 에이전트는 최상단 레이어, 정책 표시는 셀 모서리에 그린다.
  가치 색상은 시작점·벽·목표·위험 색상을 덮지 않는다.
- 방문하지 않은 상태에는 정책을 추측해 그리지 않는다. 최댓값이 여러 개인 상태는 `⋯`,
  유일한 최댓값은 화살표다. 실제 탐욕 실행의 동률 규칙은 기존 최저 인덱스 선택을 유지하며
  시각화 설정에서 이 차이를 설명한다. 현재 목표 수집 마스크와 일치하는 Q행만 표시한다.
- 속도는 기존 1–100 슬라이더와 Scheduler 연결을 유지한다. `Scheduler.setSpeed()`는 이제
  **이전 모드의 API로 기존 타이머를 취소한 뒤** 새 모드를 저장한다. timeout↔rAF 양방향
  취소와 오래된 콜백 무효화를 회귀 테스트로 확인했다.

## 맵 편집·갤러리

편집기에서도 큰 평면 2D 맵과 플로팅 도구를 사용한다. 선택, 벽, 시작점, 목표, 위험,
보상, 지우개를 제공하며 크기·보상 값·가져오기/내보내기는 속성 패널에 있다.
3–20 크기와 요소 충돌을 검증하고, 유효하지 않은 초안은 적용할 수 없다.

기존 11개 프리셋은 모두 유지한다. 썸네일 선택 → 큰 미리보기 → 선택/적용의 갤러리를
제공한다. 미리보기는 엔진을 변경하지 않는다. 편집기에서는 선택·가져오기도 초안만 바꾸며,
명시적인 적용과 확인을 거쳐 실험을 바꾼다. 학습 화면 갤러리는 ‘맵 적용’ 버튼을 사용한다.

## 새 환경 요소: 보상 타일

이번에는 전이·보상·편집·렌더링·직렬화·테스트를 모두 연결한 보상 타일을 우선 완료했다.
포털, 미끄러운 타일, 단방향 타일은 추가하지 않았다.

- 설정 필드: 선택적 `rewardTiles: { x, y, reward }[]`, 타일별 −100…100.
- 목표와 달리 종료 상태가 아니다. 성공적으로 진입하면 기존 이동 보상에 추가한다.
- 반복 진입도 매번 지급한다. 같은 칸에서 벽/경계를 향해 막힌 행동에는 지급하지 않는다.
  따라서 양의 보상 순환을 학습할 수 있으며 이 규칙을 속성 패널에도 명시한다.
- 시작·목표·벽·위험과 중복 배치하지 않는다. 좌표 정수/범위, 값, 중복 좌표를 검증한다.
- 기존 좌표+목표 마스크 상태 표현은 유지한다. 타일 보상은 방문 이력과 무관하므로 추가
  수집 마스크가 필요 없다. 실제 Q-Learning과 SARSA 갱신에 보상이 반영됨을 테스트했다.
- JSON version 1에 선택 필드를 추가했다. 기존 파일은 그대로 읽으며, 새 타일은 내보내기와
  재가져오기를 거쳐 동일하게 복원된다. 렌더 모델의 `cellRewards`로 표시한다.

## 홈 애니메이션

설명용 시연이라는 표시를 유지하며 자동 재생·목표 후 반복·탐색/활용 비교·일시정지를
지원한다. 모션 감소 요청 시 자동 재생을 시작하지 않고, 요청이 바뀌면 정지한다.
화면을 떠나면 시연 타이머를 정리한다. 홈에서도 벽·에이전트의 돌출 효과를 제거했다.

## 제한 사항

- 새 환경 요소는 보상 타일 1종을 완료했다. 포털·미끄러움·단방향은 미구현이다.
- 모바일은 Edge 터치/화면 에뮬레이션이며 실제 iOS/Safari/Android 기기는 검증하지 않았다.
- 20×20 고속 실행의 단기 응답성을 확인했으며 장시간 메모리·프레임 성능 프로파일링은 하지 않았다.
  기존 학습 이력은 계속 메모리에 누적된다.
- 상태 보존은 현재 세션 안의 화면 이동 범위다. 새로고침·탭 종료 후 복원은 없다.
- 작은 모바일 화면의 20×20 셀은 작아진다. 정밀 편집은 확대와 격자 내부 패닝을 사용한다.
