# V5 후속 — 포털 클릭 방향, 균열 아이콘, Backspace 삭제, 모바일 십자 키패드, 홈 '맵 만들기'

브랜치 `feat/mobile-editor-terrain-portals-v5` (기준: `5f68902`). `main` 병합·배포는 하지 않았다.

## 1. 포털 반복 클릭으로 방향 설정
포털 도구로 이미 놓인 **완성된 쌍의 끝점**을 다시 누르면 눌린 끝점이 **도착지점**이 된다 (`cyclePortalAt`, `editorOperations.ts`).

| 상태 | 누른 칸 | 결과 |
|---|---|---|
| 양방향 A↔B | A | B → A (`ends=[B,A]`, `directed`) |
| B → A | B (출발점) | A → B (`ends=[A,B]`) |
| 단방향 | 현재 도착지점 | 양방향 A↔B (`directed` 제거) |

- 기존 규칙 유지: `directed` + `ends[0]→ends[1]`, 끝점 배열 순서가 곧 방향. 속성 패널의 양방향/단방향·방향 뒤집기와 같은 데이터를 바꾼다(테스트로 상호 일관성 확인).
- 도구에 자동 선택된 ID와 무관하게 **눌린 칸이 속한 쌍**만 바뀐다. 다른 쌍은 불변.
- **미완성 쌍(끝점 1개)** 은 아무 일도 하지 않아 중복 끝점이 생기지 않는다.
- 클릭 1회 = 전환 1회: 마우스(pointerdown/up + 뒤따르는 click), 터치 탭, 키보드 Enter/Space 모두 한 번만 전환하고 Undo 한 번에 되돌아간다(기존 스트로크의 click 흡수 장치 사용).
- JSON: 방향이 바뀐 맵은 v4로 내보내고 왕복이 동일. 끝점 이동·삭제·Undo/Redo 후에도 A/B 슬롯 유지.

## 2. 무너지는 바닥 아이콘
`fragileGlyph.ts`의 한 정의(`FRAGILE_SLAB`, `FRAGILE_CRACKS`)를 **도구 아이콘과 지도 타일이 공유**한다. 번개 대신 한 점에서 길이·각도가 다른 균열 3개가 퍼지고 작은 가지 하나가 있는 깨진 판이다 (처음 안은 120° 간격이라 프로펠러처럼 보여 비대칭으로 바꿨다).
- 정상: 크림색 판 + 가는 갈색 균열. 붕괴: 어두운 판 + 굵은 밝은 균열 + 점선 테두리 + 충격점(차단된 칸임을 색에 의존하지 않고 표시).
- 붕괴 규칙·엔진·학습은 변경 없음(`data-collapsed` 속성과 상태 키 그대로).
- 스크린샷: `docs/screenshots/v5b/fragile-tool-icon.png`, `fragile-tiles-intact-and-collapsed.png`.

## 3. Backspace / Delete 삭제
마지막으로 **클릭·배치한 칸**(`selectedCell`)의 요소를 어떤 도구에서든 지운다(예전에는 선택 도구만).
- 시작점·마지막 목표 보호와 안내 문구 유지, 포털 끝점 삭제 시 쌍이 미완성이 되어 적용이 막히고 오류 안내, Undo/Redo 지원.
- 대상이 비어 있으면 아무 일도 없고 기록도 남지 않는다.
- 입력창·숫자 필드·포털 ID에서는 글자 삭제만 일어난다(기존 입력 예외 유지). 편집기가 비활성이거나 직접 플레이 중이면 동작하지 않는다.
- 드래그로 여러 칸을 칠한 직후에는 **첫 칸**만 대상이다.

## 4. 모바일 십자 방향키 (≤760px)
CSS Grid 3×3: 위는 1행 가운데, 왼쪽/오른쪽은 2행, 아래는 3행 가운데, 가운데는 비움. 버튼 셀 56×52(낮은 화면 52×48), 딥블루 화살표·흰 표면. DOM 순서(↑ ← ↓ →)는 키보드 탭 순서로 유지. `HeldMovement`는 그대로: 길게 누르면 반복(200 ms 후 100 ms 간격), pointerup/cancel/lost capture/창 blur/일시정지/종료 시 중단. `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none`.
- 격자 공간: 수정 전 320×568에서 편집기용 줌 오버레이가 직접 플레이 격자까지 덮던 규칙 누출을 바로잡았고, 모바일에서 `(R)`/`(Esc)` 키 힌트를 숨겨(접근성 이름은 그대로) 헤더를 한 줄로 줄였다. 격자는 320×568·390×844·430×932 모두 화면 높이의 36% 이상.
- 데스크톱의 방향키/WASD, 기존 가로 한 줄 패드(≥761px)는 유지.

## 5. 홈 '맵 만들기'
`학습 시작하기`(Primary) · `맵 만들기`(Secondary 외곽선) · `알고리즘 알아보기`(Text). 누르면 `맵 편집하기`로 이동. 슬로건·설명은 되살리지 않았다. 폰에서는 모든 버튼 높이 ≥44px, 320/390/1440에서 가로 넘침 없음.

## 7. 남은 한계
- 실기기 터치는 확인하지 못했다(Edge iPhone 13 프로필 + CDP 터치).
- 단방향 포털의 한쪽 끝점을 삭제한 뒤 같은 ID로 다시 놓으면 새 끝점이 B가 된다(미완성 쌍이라 적용은 막힘, 클릭 전환/뒤집기로 바로잡음).
- Backspace 대상은 마지막 클릭 칸 하나뿐이다(여러 칸 선택은 없음).
- 모바일 직접 플레이에서 줌/따라가기 막대는 격자 아래에 남아 있다(큰 맵 이동용).
