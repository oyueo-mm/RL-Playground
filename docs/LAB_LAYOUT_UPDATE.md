# 학습 환경 UI 추가 수정

`feat/home-redesign`의 홈·실험 상태 보존 구조를 유지하며 학습 화면을 개편했다.

## 레이아웃과 분석

- 기존 격자 옆 정보 열을 없애고, 격자가 전체 행을 사용하는 중앙 캔버스로 변경했다.
- 표시 너비는 화면 높이와 맵 비율에 따라 결정하며 최대 960px, 가용 너비에 맞춰 축소된다.
  1440×1000 데스크톱의 기본 7×7 맵은 기존 기본 336px에서 720px로 확대된다.
- 순서는 격자 → 실행/속도 → 정책·가치·경로 토글 → 에피소드 단계 뷰어다.
  알고리즘과 하이퍼파라미터는 접이식 학습 설정에서 조절한다.
- 분석은 격자 아래의 **기본 닫힘 접이식 패널**이다. 상단의 ‘통계 보기’로 열고,
  상단 또는 패널 내부 ‘통계 숨기기’로 닫는다. 열면 분석 위치로 이동한다.
- Inspector, Q-value, Statistics, 종료 사유, Reward Chart, Learning Progress,
  Episode Trajectory를 모두 유지했다. 데스크톱은 분석 카드 2열, 좁은 화면은 1열이다.
- `hidden`만 변경하므로 분석 컴포넌트를 언마운트하지 않는다. 선택한 셀·에피소드,
  학습 실행 상태, Q-table, 이력과 패널 내부 상태를 보존한다.
- ‘학습 결과 보기’ 메뉴에 진입하면 분석을 열고 통계로 이동한다.

## 속도 슬라이더

- 네이티브 range: 1–100, 간격 1. 키보드 방향키·Home·End를 지원한다.
- 1–80은 1000→20ms/스텝의 로그 간격, 81–100은 1→100스텝/프레임의 로그 간격이다.
  60Hz 기준 약 1→50스텝/초의 관찰 구간에서 약 60→6000스텝/초의 배치 구간으로 이어진다.
- UI에서 만든 `SpeedSetting`을 기존 `engine.setSpeed()`에 전달한다.
  기존 Scheduler의 재예약 동작을 사용하며 실행 중 속도 변경도 실험을 초기화하지 않는다.
- 현재 모드의 실제 설정값과 한국어/영어 보조 설명을 표시한다. 배치 크기의 정수 반올림으로
  같은 값이 연속되어도 사용자의 슬라이더 위치를 유지해 키보드 이동이 멈추지 않게 했다.
- 기존 실험에서 주입한 범위 밖 속도는 슬라이더 위치만 한계값으로 표시하며 자동 변경하지 않는다.

## 사이드바

브랜딩 구조를 유지하고, 토글을 흰 배경·테두리가 있는 48px 높이 버튼으로 강조했다.
햄버거·텍스트·접기 표시를 정렬하고 메뉴 간격과 선택 표시를 통일했다.
접힌 상태는 아이콘 중앙 정렬, 모바일 드로어는 기존 포커스·Escape 처리를 유지한다.

## 검증

- `npm run lint`: 통과.
- `npm test`: 43개 파일, 941개 테스트 통과.
- `npm run build`: TypeScript 및 Vite Production 빌드 통과.
- `npm run test:e2e`: Edge 데스크톱·모바일 6개 테스트 통과.
- 브라우저에서 큰 격자, 패널 기본 닫힘, 열기 전후 격자 너비 불변, 셀 선택 유지,
  속도 방향키·Home·End 및 모드 경계 이동, 메뉴, 가로 넘침을 검증했다.
- `/RL-Playground/` 경로와 기존 GitHub Pages 설정을 유지한다. 배포는 수행하지 않는다.

## 제한 사항

- 배치 모드의 실제 처리량은 화면 주사율·브라우저와 맵/실험 크기에 따라 달라진다.
  최대 100스텝/프레임이며 실시간 처리량을 보장하는 수치는 아니다.
- 분석은 옆으로 격자를 줄이는 드로어 대신 아래로 펼쳐진다. 많은 결과는 세로 스크롤이 필요하다.
- 모바일 검증은 Edge 에뮬레이션이며 실제 iOS/Android 기기는 확인하지 않았다.
- 새로고침 후 복원 등 이전 보고서의 제한 사항은 동일하다.

주요 파일: `Simulator.tsx`, `App.tsx`, `index.css`, `i18n.ts`, `SpeedControl.tsx`,
`speedSlider.ts` 및 대응 단위·통합·E2E 테스트.
