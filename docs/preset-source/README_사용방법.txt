RL Playground — 사용자 제안 프리셋 20종 (검토용 초안)
================================================

구성
- 쉬움 / 보통 / 어려움 / 매우 어려움 각 5종 = 총 20종
- json/             : 앱 '맵 편집하기' -> '속성 / 파일' -> 환경 불러오기에 사용할 JSON v2
- solutions/        : 맵별 성공하는 행동 시퀀스 (0 위, 1 아래, 2 왼쪽, 3 오른쪽)
- previews/         : 맵별 PNG 이미지
- 01~04_...png      : 난이도별 5개 미리보기
- 00_전체_20개_미리보기.png : 전체 모아보기
- 프리셋_20개_인터랙티브_갤러리.html : 브라우저에서 단독으로 열어 맵별 미리보기와 경로 재생, JSON 저장 가능
- 목록_검증결과.json  : 맵 개요와 경로 검증 지표

확인 방법
1. HTML 파일을 Chrome/Edge로 열고 난이도 탭에서 맵을 고릅니다.
2. '검증 경로 재생'을 클릭해 목표 수집 과정을 관찰합니다.
3. '현재 맵 JSON 저장'으로 맵 파일을 내려받습니다.
4. RL Playground 로컬 앱에서 맵 편집 -> 속성/파일 -> 환경 불러오기를 선택합니다.
5. UI에서 실제 적용/직접 플레이를 진행해 사용성을 확인합니다.

검증의 의미
- 모든 20개 맵에서 시작점부터 모든 Goal을 수집하고 폭탄에 들어가지 않는 유효 행동 시퀀스를 찾았습니다.
- 경로 탐색/재생은 현재 GitHub GridWorldEnv.step() 전이 규칙(포털 한 번 발동, 단방향 출발 제한,
  스위치 그룹 전환, 부서진 타일 재진입 차단, 모두 수집 시 완료)을 Python/HTML에 재현해서 검증했습니다.
- 성공 경로는 반드시 최단 경로가 아닙니다. RL 모델 학습 수렴/성능도 검증한 것이 아닙니다.
- 실제 RL Playground 브라우저에서 이 20개 파일을 하나씩 불러오는 통합 테스트는 아직 수행하지 않았습니다.
- 편집/프리셋 코드의 기존 JSON v2 포맷에 맞춰 작성했습니다.
- 기존 저장소의 프리셋 목록을 변경하거나 배포한 것은 아닙니다. 검토용 별도 파일입니다.

맵 난이도는 구간별 배치의 복잡성(맵 크기, 목표 수, 환경 요소)을 바탕으로 한 설계상의 분류입니다.
