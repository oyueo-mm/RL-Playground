# RL Playground — 30개 개편 프리셋

## 구성
- 쉬움 / 보통 / 어려움 / 매우 어려움 / 극악: 각각 6개, 합계 30개
- 기존 20개는 전수 감사 후 포함; 10개 신규(기본 난이도별 1개, 극악 6개)
- json: RL Playground version 2 환경 데이터
- solutions: 검증 경로(숫자 행동 0=위/1=아래/2=왼쪽/3=오른쪽)
- previews, 난이도별 시트, 전체 이미지
- reports: 수정 전 20개 감사 결과 및 수정 후 30개 검사 결과

## 현재 애플리케이션과의 호환성
- 01~24: 20×20 이하로 현재 버전 가져오기 가능하도록 설계
- 25~30 극악: 24×24~48×40. 현행 validateFeatures 최대 20 제약 때문에 *현재 즉시 가져오기 불가능*.
  64×64 상한을 지원하는 앱 업데이트 이후 가져와야 함.

## 검증 단계와 제한
- 맵의 구조 유효성과 각 성공 경로는 Python에 재현한 실제 GridWorldEnv의 전이 규칙으로 확인.
- 정적 구조 그래프에서는 모든 문을 열고 모든 붕괴 지형이 존재한다고 가정해 방향 감옥을 탐지.
- 정적 그래프는 동적 문·붕괴 상태에서 발생 가능한 모든 영구 막힘을 증명할 수 없다.
- 모든 맵이 사람에게 극악 난이도라고 검증된 것은 아님. 사람 테스트 및 난이도 조정 필요.
- 대형 극악 맵은 일반 표 기반 Q-learning에서 대규모 상태 공간과 학습 정체를 유발할 수 있음.
- 브라우저의 실제 TS GridWorldEnv 검증 및 장기 학습 벤치마크는 Codex 업데이트 시 추가 권고.
- 맵의 정적 최단경로 감사는 근사 지표이며 실제 엔진의 최단해 인증이 아님.

## 압축 풀어 사용하기
- 01~24 맵은 맵 편집기 환경 JSON 가져오기에서 가져오고 환경 적용을 누르면 사용 가능.
- 25~30은 맵 크기 확장 후 사용 가능.
- 성공 경로는 정답 힌트·홈 시연 용도이며 최단 경로를 보장하지 않음.

## 로컬 플레이 테스트
`30종_직접플레이_갤러리.html`을 로컬 브라우저에서 열면 30개 맵을 직접 플레이하거나 경로 재생 가능. WASD/방향키, 화면 맞춤, 확대, 모바일 방향 버튼을 지원하며 네트워크 연결 불필요. 이는 앱의 실제 학습 엔진이 아닌 동일 규칙으로 만든 독립 데모임.
